# Skilloop Zone

五领域前沿社区与技能互助网页原型。

公开链接：https://monkeyl-code.github.io/skilloop-zone/

## 本地运行

运行 `npm start`，打开 http://127.0.0.1:8792/ 。页面使用原生 HTML、CSS、JavaScript，无需构建。Node.js 仅用于测试；网站运行不依赖第三方 CDN。

运行检查：`npm ci`，然后 `npm run check` 和 `npm test`。

## 体验路径

1. 起始页 → 逛逛前沿 → 阅读焦点文章。
2. 文末选择蓝色“我能教的”或橙色“我想学的”，保留文章主题进入互助区。
3. 查看技能卡 → 发起积分互助或直接互换。
4. 第一次操作时创建示例昵称并体验已实名状态，起步积分只发一次。
5. 约定页展开“模拟伙伴操作”，模拟接受、提交或确认；自己的成果单独填写。
6. 双方确认后查看订单和积分记录。可从“我的”编辑技能卡、导出基础海报。

Python／Photoshop 的入门路线各有五级。其他程度自行约定；互助达人是完成十次有效带学的贡献身份，没有收费权益或推荐加权。

## 资讯后台

页脚“资讯后台”打开 `admin/`。复用此前 Routing Brief 的桌面布局、素材库、内容创作、待发布／已发布、三栏富文本编辑、自动保存、预览及撤回交互。

按用户提供表格的 CMS-01／Q28 更新中英文富文本、图片、草稿隔离、显式发布与下架。草稿保存不会修改发布快照；发布后更新同一浏览器前台列表，其他访客看到 GitHub 部署版本。

后台使用本项目独立的本地演示适配器，不连接原项目 API，不具备真实管理员鉴权。全站原型数据保存在浏览器 localStorage，不能跨设备同步。

## 数据与媒体

当前人物、互助、身份、验证、积分及举报均为模拟数据。没有真实收款、证件上传、消息发送或媒体采集。独立 SVG 主视觉与五领域封面均为媒体占位，后续可换成用户提供素材。

公开教程链接及许可说明见 [设计文档](docs/designs/2026-11-02-prototype-direction.md)。页面结构参考 Simbi 的服务分类、服务单位和伙伴资料，阅读区采用内容社区常见的文章、作者、收藏和相关推荐结构。

入口使用 hash 路由，后续部署继续推送 `main`，保持仓库名与 Pages 地址不变。
