# 桌面体验调整

2026-11-02

## 确定方向

技能互助是产品重心。前沿资讯是新客接触社区的前奏，文章和列表页均有明确互助入口。

- 起始页极简：品牌、短文案、进入互助区的主按钮、查看资讯的次入口。点击主按钮时双环短暂收拢，尊重减少动态效果的设置。
- 资讯页界面使用黑白灰，图片和 Logo 保留彩色。五领域内容用一条主展示和四条次内容排在桌面首屏，底部蓝橙互助入口可见。更多文章分页，搜索与领域筛选保留。
- 文章阅读区采用中性色，文末互助区域带底色，呈现从内容阅读到人与人互助的区别。
- 内容与底部引导之间有独立分隔线，线上下留白；资讯列表保持一屏可见，文章末尾间隔更宽。
- 互助区采用有底色的三列社区布局：左侧讨论与领域导航、中间帖子流、右侧个人状态与同好活动。内容以具体问题和来回回复为中心，技能对应关系用小型蓝橙区域保留。
- 新增主题详情、发布互助、回复讨论。发帖需要实名体验；回复需要登录。发帖、回复不增发积分。
- 十次有效互助显示互助达人；积分和交易规则沿用现有版本。
- 本轮不进行手机布局优化或手机视觉验收。

## 参考证据

通过 Edge + OpenCLI 实际读取 V2EX 首页与 Discourse Meta 最新话题页。

- V2EX：节点导航、个人头像、具体主题标题、回复数、最后回复与侧边社区信息。采用其讨论优先的信息结构，不复制原站帖子、人物或广告。
- Discourse：最新话题、分类、回复与活动信息。采用主题列表到会话详情的路径，不照搬产品装饰或商业功能。

社区人物、帖子和回复均为本项目编写的示例；不代表真实活动或用户。

## 实现与检查

`desktop.css` 管理新的桌面层次；既有订单、资料、后台的基础样式保留。`src/community-data.js` 提供示例话题；本地状态保存用户发布与回复。正文与用户文本转义后展示。

旧版本未编辑的资讯种子内容会显示新版事实型标题和摘要；有发布历史或自定义标题的内容不被替换。

检查重点：起始页主入口、文章上下文跳转、讨论回复、发起互助、求助帖提供帮助的方向、积分规则、后台草稿隔离，以及常见桌面尺寸下资讯内容和底部入口的可见性。

## 验证结果

- 17 项回归通过，包括发帖／回复不奖励积分、原有互助结算、后台双语编辑与草稿隔离、旧种子文案更新不覆盖保存过的草稿。
- Edge 检查资讯页 1280×720、1366×768、1440×900：五领域内容、底部入口与页脚信息完整容纳，横纵均无页面溢出。
- 按最新要求加分隔线后，再验 1280×720 与 1366×768：内容到线约 11—14px，线到引导约 20px，仍不滚动。文章末引导区域的上间隔为 63px。
- Logo 与媒体计算样式均无灰度滤镜。旧版纯黑白媒体截图已被彩色版本验收替代。
- 极简起始页在 1366×768 内完整显示，点击后出现短动画并进入六条示例讨论的互助页。
- 本轮不做手机优化。
