# 社区模块、教与学切换及后续匹配

2026-11-02

## 当前原型

五领域仍为 AI 与编程、视觉与影像、音乐与声音、语言与表达、生活与手作。顶部导航保持前沿资讯、技能互助、同好活动、我的。

Spaces 作为领域空间导航，每个空间进入对应讨论。切换教／学时保留所选空间和来自文章的上下文。

Featured topics 展示明确标记为社区精选的讨论，卡片包含领域、标题、作者与回复数，点击进入会话。当前选择来自编辑整理，不代表用户个性化推荐。

Upcoming events 展示领域相关的免费同好活动，包含封面、日期、时段及报名人数，点击进入活动详情，可报名或取消；列表与详情共享报名状态。

教与学通过分段 Switch 切换：

- 我想学：暖橙背景，包含空间、精选话题、完整社区讨论与活动入口，支持发布需求、回复和约互助。
- 我能教：冷蓝背景，主区收为教学卡。编辑技能、入门任务、帮助范围、方便时间、作品文件名和是否接受新互助。使用同一份个人资料，不再独立维护重复的“教师账户”。
- 未登录可以浏览教学页轮廓，填写时登录。文件只记录本机选择的文件名，不上传或伪造作品认证。
- 教学资料采用显式保存，保存后个人技能卡同步；暂停新互助不删除已有订单。
- 教学范围保存到技能卡的能力描述，个人简介保留原内容；两者各司其职。

原型继续不做收费开班、积分兑现和导师商业权益。本轮聚焦桌面，不增加手机优化。

## 后续匹配推荐系统草案

目标：帮助有明确学习目标的人找到能提供相应帮助、时间合适且愿意接受互助的伙伴；推荐结果给出可理解的原因。

第一阶段使用规则匹配。候选来自公开技能卡和互助需求，而非从示例人物中固定挑选。

| 输入 | 用途 | 当前状态 |
| --- | --- | --- |
| 我能教／我想学 | 双向技能与需求匹配 | 原型已保存，名称仍是自由文本 |
| Python／PS 入门任务 | 对齐具体作业及前置条件 | 各五级已定义 |
| 非入门技能与作品 | 按具体能力和目标协商 | 不设统一高阶分级 |
| 可用时段、时区、形式 | 过滤无法共同安排的候选 | 当前仅自由文本时间；正式匹配前需改为结构化时段 |
| 是否接受新互助 | 排除暂停接待者 | 已加入教学卡 |
| 互助方式和积分预算 | 区分直接互换、积分求助 | 已有订单字段；候选报价需另行结构化 |
| 作品与历史反馈 | 提供能力和履约依据 | 原型展示，不当成真实认证 |

候选过滤：排除本人、暂停接待者和不支持的互助形式；根据明确技能、任务、共同时间与预算筛选。实名作为参与互助前的资格，不以公开证件信息参与排序。

排序建议：目标任务符合 → 双方需求互补 → 时间更合适 → 有对应作品与相关反馈。积分余额、海报付费和互助达人身份不作为排名加权。

展示示例理由：“可带 PS S2 蒙版”“你能提供对方想学的 Python P2”“周六有共同时间”。不使用没有验证依据的百分比概率。

没有结果时提供调时间、改互助方式、看同空间讨论或参加活动，不静默降低能力要求。资料不足的新客先看空间精选内容，补充目标后再尝试匹配。

第二阶段在真实使用数据形成后再评估：推荐点击、有效预约、完成互助、取消原因和是否达成约定成果。不能把示例数据或帖子互动量当作学习成效。

本轮不实现或宣称已上线匹配引擎，先完成社区入口和资料结构。

## 验证

- 18 项回归测试通过，覆盖 Spaces／精选／活动入口、保留文章上下文的教／学切换、教学卡和个人资料同步、暂停状态，以及原有互助积分与后台发布流程。
- Edge 桌面 1440×900 截图检查：学习页为暖橙色社区，教学页为冷蓝色资料卡；学习页呈现五个 Spaces、两条精选话题和两场活动。
- 1366×768 浏览器检查：两个模式均无横向溢出；教学模式不显示讨论流，学习模式显示精选与讨论。
- 只读参考了 Discourse 官网与 Demo Sandbox 的公开社区结构，没有操作其注册、发帖或测试内容。
