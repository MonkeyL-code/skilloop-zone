# 原型实施与验收

2026-11-02

## 已确认的补充决定

- 新用户实名体验后一次获得 2 积分；等量直接互换不要求余额。
- 十次有效带学显示“互助达人”，不设置独立导师专区，不附加商业权益或推荐加权。
- 链接默认显示起始页。Logo 与主视觉独立，沿用蓝橙风格。
- 新客可以先读文章；文章底部双色入口携带主题进入互助区。
- 用户提供飞书主表 revision 137、需求表 revision 71，CMS-01／Q28 明确双语富文本／图片、草稿／预览／显式发布／下架，保留布局，不增加复杂审批。本项目实现其原型交互，不接原业务服务。

## 实施

前台使用原生静态页面与 hash 路由；`src/state.js` 处理积分、实名体验、订单状态，`src/content.js` 隔离草稿和发布快照。界面与逻辑分开，可直接部署至既有 GitHub Pages。

`admin/` 复用已有后台的编辑器和布局，独立演示适配器提供素材、稿件、草稿保存、发布与撤回。保留五领域，中文／英文各有富文本工具栏。当前浏览器的前台读取发布快照。

## 验证证据

- 14 项自动化测试：新客文章到互助完整路径；后台双语编辑、预览、保存、发布、撤回；草稿不泄漏；重复路径拦截；积分赠予一次、预约／释放、双确认、重复确认、直接互换、部分交付取消和活动不发积分。
- Edge 实际验证：起始页资源全部加载；从文章文末打开带主题互助页；示例身份创建；积分互助完成后余额 2 → 1、预约积分为 0；后台双语工具栏及三栏布局正常。
- 390px 实际浏览器框架逐页检查：起始、前沿、文章、互助、技能卡、入门任务、活动、我的均无横向溢出。订单手机截图已目视检查。
- 截图只作为本地 QA，不作为网站媒体或真实用户证据。

## 范围

原型没有真实认证、实名、支付、媒体采集、代码运行、PSD 检测、跨设备数据或生产管理权限。文案在相应体验节点说明数据为模拟／保存在当前浏览器，正式功能需另行接入。
